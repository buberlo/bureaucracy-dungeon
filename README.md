# Bureaucracy Dungeon

> Fight monsters by filing forms, stamping scrolls, and surviving the audit.

A dungeon crawler where every attack is a piece of paperwork that must be completed under time pressure. Red tape traps, missing attachments, and rubber stamps become cooldowns and resources. The boss is a weary auditor who can nullify your whole dungeon run if one form is unsigned.

## Features
- Form cards let players cast spells by filling fields before a timer expires
- Stamp meter limits high-powered actions and restores by archiving weak spells
- Red tape rooms create branching paths with penalties for incomplete paperwork
- Auditor boss checks your submission log and deletes unattached evidence

## Stack
- Phaser
- TypeScript
- Web Audio API
- IndexedDB

## Getting started
```
npm install && npm run dev
```
